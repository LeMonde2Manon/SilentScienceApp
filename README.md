# SilentScienceApp

SilentScienceApp is an open-source scientific AAC web application for non-verbal children.
It allows users to ask science questions using pictograms (e.g., “Why is the sky blue?”,
“Why does it rain?”, “Why do volcanoes erupt?”) and receive AAC-friendly text answers
generated by an external AI.

The app interprets pictograms, reconstructs the intended question even if the child clicks
them in any order, and provides clear scientific explanations adapted to AAC users.

## Scientific Purpose

SilentScienceApp helps children explore scientific concepts such as:
- astronomy (sky, Moon, planets)
- weather (rain, clouds, wind)
- geology (volcanoes, rocks, fossils)
- biology (animals, living things)
- physics (light, color, movement)

The goal is to give non-verbal children access to scientific reasoning and “why” questions.

## Features

- Locked child mode (restricted UI, no navigation)
- Parental mode with PIN and content filtering
- Pictogram-based question building
- AI-powered interpretation of pictogram sequences
- AAC-friendly scientific explanations
- Context-based pictogram suggestions
- PWA support (installable, fullscreen, offline)
- Audio synthesis (TTS)

## How it works

1. The child selects pictograms (e.g., “sky”, “blue”, “why”).
2. The app interprets the pictograms and reconstructs the question.
3. An external AI generates an AAC-friendly scientific explanation.
4. The app reads the answer aloud and suggests relevant pictograms.

The child does not need to form a sentence or understand word order.

## Architecture

SilentScienceApp includes:
- Child mode: simplified, locked interface
- Parent mode: configuration, filtering, safety rules
- AI module: interpretation, AAC-friendly text generation, scientific reasoning
- Backend API: communication with external AI services
- PWA layer: installation, offline mode, kiosk-like behavior
